NOTAS PARA EL PROGRAMADOR
==========================================================================================
1. El separador de campos es el carácter |.
2. Las regiones, países y orientaciones aparecen como encabezados.
3. Conservar siempre el nivel A/B/C/D: define cómo debe tratarse editorialmente el medio.
4. Para automatización, no sumar republicaciones de una misma agencia como confirmaciones independientes.
5. Una noticia sensible debe contrastarse con fuente primaria, agencia, medio local y parte enfrentada.
